Our fundamental insights were derived from a plastid phylogenetic tree: built from dereplicated genomes from 2000 plastid genomes from NCBI GenBank.

We firstly dereplicated these genomes using an ANI of 95%, resulting in 898 plastid genomes with annotated proteins.

We then picked 55 genes that are ultra-conserved in these genomes, to infer a phylogenetic tree.
