## Plastid/Chloroplast Genomes

This page provides an interactive table of the plastid/chloroplast genomes used in the analyses for ChlORIS curation. These genomes have been dereplicated from the original ~2,250 sequences and are organized by representative genome clusters.

### Features

- **Search and Filter**: Use the search boxes in each column to filter by genome name, tree status, or other criteria
- **Sort**: Click on column headers to sort by any field
- **Pagination**: Browse through genomes using the pagination controls (10, 25, 50, or 100 per page)
- **Multiple Selection**: Select multiple rows to compare or analyze them together
