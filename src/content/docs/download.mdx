## HMM Library
Curated profile Hidden Markov Models (HMMs) for 493 orthgroups in HMMER3 format, suitable for remote homology searches.

<LinkButton href="../downloads/ChlORIS_hmms.tar.gz" icon="download">ChlORIS_hmms.tar.gz</LinkButton>

## Multi Sequence Alignment (MSA)
Multi Sequence Alignment (MSA) of 493 orthogroups (cover same proteins as HMM library) in aligned FASTA format.
<LinkButton href="../downloads/ChlORIS_msa.tar.gz" icon="download">ChlORIS_msa.tar.gz</LinkButton>

## Phylogenetic Tree
The phylogenetic tree described in species page of the website. The phylogenetic tree including representative plastid genomes and cyanobacterial outgroups in newick format.

<LinkButton href="../downloads/ChlORIS.contree" icon="download">ChlORIS.contree</LinkButton>

## Orthogroups with unknown functions
These are orthogroups with members mainly hypothetical open reading frames (ORFs), with non-canonical names.
<LinkButton href="../downloads/OGs_unknown.tar.gz" icon="download">Unknown_OGs.tar.gz</LinkButton>

## Pfam-Protein mapping matrix in tab-delimited format.
The table stores the HHsuite results of probability of 989 Pfam domains being present in 470 proteins. 
<LinkButton href="../downloads/Pfam_Protein_Mapping.tsv" icon="download">Pfam_Protein_Mapping.tsv</LinkButton>

## mmCIF files for all proteins displayed.
221 protein structures in **.cif** format predicted from .a3m alignments by AlphaFold3, revealing co-evolutionary structural features.

<LinkButton href="../downloads/protein_cifs.tar.gz" icon="download">protein_cifs.tar.gz</LinkButton>

## Metagenomic database using ChlORIS HMMs
A metagenomic database utilizable by HMMER3-based tools like CheckM, we will provide customized scripts soon to facilitate the use of this database for metagenomic binning and quality assessment.

<LinkButton href="../downloads/protein_msdb.tar.gz" icon="download">protein_msdb.tar.gz</LinkButton>
